# 🎨 Nexo HUD | NoPixel V Inspired

A modern and clean FiveM HUD inspired by the NoPixel V style, designed to bring a premium in-game experience to your server.

- 🎨 **Customizable HUD** – Players can customize their HUD to match their personal preferences.
- 🌈 **Admin Color Settings** – Admins can change HUD colors to match their server's theme.
- 🖥️ **Modern UI Design** – Clean, smooth, and visually appealing interface.
- ⚙️ **Easy Configuration** – Simple configuration options for easy customization.
- 🚀 **Drag & Drop Installation** – Quick and easy setup for your FiveM server.
- 🎮 **FiveM Optimized** – Designed for a smooth in-game experience.
- 💎 **NoPixel V Inspired Design** – A modern HUD inspired by the NoPixel V aesthetic.

## 📦 Installation

1. Download the latest version of **Nexo HUD**.
2. Extract the downloaded files.
3. Place the resource inside your server's resources folder.
4. Add the following line to your `server.cfg`:

```cfg
ensure nexo_hud
```

5. Restart your server or start the resource.

## ⚙️ Customization

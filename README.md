# ✨ Features

- 🎨 **Fully Customizable HUD**
  - Players can customize their HUD layout according to their preference.
  - Move, resize, hide and adjust supported HUD elements.

- 🌈 **Admin Color Management**
  - Server admins can change HUD colors.
  - Customize the HUD theme to match your server branding.

- ❤️ **Player Status System**
  - Health
  - Armor
  - Hunger
  - Thirst
  - Stamina
  - Oxygen
  - Voice Indicator
  - Weapon & Ammo Display

- 🚗 **Advanced Vehicle HUD**
  - Speedometer
  - Gear Display
  - Fuel System
  - Engine Status
  - Vehicle Lights
  - Seatbelt Status
  - Lock Status

- 🗺️ **Modern Circular Minimap**
  - Compass
  - Street Name
  - Zone Name
  - Waypoint Distance
  - Smooth Navigation Design

- 💬 **Custom HUD Chat Box**
  - Clean chat design matching the HUD style.
  - Smooth animations and modern UI.

- 🎬 **Cinematic Mode**
  - Toggle cinematic view with a simple command.

- ⚡ **Optimized Performance**
  - Lightweight client-side system.
  - Designed for smooth gameplay.

# 📦 Installation

### 1. Download Nexo HUD

Place the resource inside your FiveM resources folder:

```
resources/[hud]/nexo-hud
```

### 2. Add to server.cfg

```cfg
ensure nexo-hud
```

### 3. Restart your server

The HUD will automatically load when players join.

All settings can be changed through the configuration files.

You can customize:

- HUD colors
- HUD position
- HUD size
- Opacity
- Display options
- Speed settings
- Framework settings

---

# 🎮 Player Settings

Players can open the customization menu:

```
/hudsettings
```

Available options:

✅ Move HUD elements  
✅ Resize HUD elements  
✅ Hide unwanted elements  
✅ Change personal HUD preferences  
✅ Save settings automatically  

Player settings are saved locally and do not require a database.
